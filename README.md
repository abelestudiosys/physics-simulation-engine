# Physics Simulation & Validation Engine

## Overview

Modular AI-based system for structured interpretation, validation, and resolution of physics problems. Designed for technical and university-level education, with dynamic mathematical rendering using MathJax and HTML/CSS integration with PDF export capability.

## System Architecture

The engine operates on a **34-module hierarchical architecture** divided into two main layers:

### Cognitive Layer (Phase A)
- Automatic exercise classification (Level 1, 2, or 3)
- Full physical reasoning sequence
- Dimensional coherence validation
- Physical consistency verification before rendering

### Visual Layer (Phase B)
- Automatic mode selection based on exercise complexity
- HTML rendering with MathJax mathematical notation
- Anti-overflow control for web and PDF output
- Dynamic vertical expansion without horizontal compression

## Rendering Modes

| Mode | Activation | Focus |
|------|-----------|-------|
| **COMPACT** | Level 1 exercises — direct calculation | Speed and visual clarity |
| **ANALYTICAL** | Level 2 & 3 — physical interpretation required | Deep conceptual understanding |

> When in doubt, the system always defaults to **ANALYTICAL** mode.

## Physics Domains Covered

- Kinematics (MRU, MRUA, relative motion)
- Dynamics (Newton's Laws)
- Energy and Work
- Gravitation
- Oscillations and Waves
- Basic Electricity
- Basic Thermodynamics

## Key Features

- **Automatic exercise classification** before any calculation
- **Mandatory physical reasoning** — no formula substitution without conceptual explanation
- **Cross-validation** — results verified for physical coherence and dimensional consistency
- **Dual rendering** — optimized HTML output for both screen and PDF export
- **Modular scalability** — each exercise is independent; any number can coexist in one document
- **MathJax integration** — professional mathematical notation rendering

## Conflict Resolution Priority

When rules conflict, the system resolves strictly in this order:

1. Physical coherence
2. Pedagogical integrity
3. Structural stability
4. Readability
5. Visual aesthetics
